# AGENTS.md

Vanilla HTML5 canvas Asteroids clone. No build, no bundler, no dependencies, no tests.

## Run / verify

- Open `index.html` directly, or `npx serve .` then visit port 3000.
- Only `index.html`, `game.js`, `favicon.svg` are load-bearing; `game.js` must stay a classic
  script (no `import`/`export`) because it is loaded via `<script src>` and shares globals.
- There is no automated test or lint step. Verification is manual: load the page, play, check
  the browser console. Do not claim a change is "tested" without that.

## File layout

- `game.js` is the entire game (423 lines): input, entities, state machine, update, draw, loop,
  all in one file. Keep new code in the existing section-comment blocks rather than adding files.
- `index.html` holds the canvas size, page CSS and the script tag.

## Non-obvious constraints

- Canvas size is duplicated: `width="800" height="600"` in `index.html` AND `const W`/`const H`
  in `game.js`. Change both or rendering and wrapping desync.
- Input is keyed by `e.code` (physical key), so use `ArrowLeft`, `Space`, etc. — never `e.key`.
- `pressed(code)` is edge-triggered and self-clearing. Call it at most once per frame per key or
  the input is silently swallowed.
- `keys` / `justPressed` are module-level globals; `pressed()` lives in the `update` path only.
- Array state is reassigned, not mutated (`bullets = bullets.filter(...)`). Follow that pattern;
  don't `splice` in place inside the loops.
- `dt` is clamped to `0.05` in `loop()`. All physics must be `dt`-scaled — never per-frame constants.
- Size-indexed arrays (`RADII`, `SPEEDS`, `POINTS`) are 1-based with an unused index `0`.
  Asteroid sizes are 1 (small) to 3 (large); `size 3` -> `20` pts, `1` -> `100`.
- Toroidal wrap is applied to positions only. Collision uses raw `dist()`, no wrapped delta, so
  entities across opposite edges do NOT collide despite looking adjacent. Preserve this behavior
  unless explicitly asked to fix it.
- `wrap()` is used for ship, bullets and asteroids; particles are not wrapped and just fade.

## Conventions

- 2-space indent, semicolons, single quotes, `const`/`let` only.
- Identifiers and comments in English; HUD/README user-facing copy in Spanish (`NIVEL`, `PUNTAJE`).
- Keep the canvas style: white 1.5px strokes on black, monospace HUD, no external assets.

## Docs vs reality

`README.md` advertises "power-ups" and a "estrella fugaz" asteroid type. Neither exists in
`game.js`. Treat the code as the source of truth; if you add these, update both files.

`.atl/` is generated by gentle-ai (skill registry + cache) and is currently untracked. Don't
commit it as part of a game change.
